# Westernstadt – Prototyp (Schritte 1–7)
1. Node.js (18+) installieren. 2. `npm install` 3. `npm start`
4. Am großen Bildschirm `http://localhost:3000/screen.html` öffnen, Spielerzahl wählen.
5. Handys im selben WLAN scannen die QR-Codes. Dann "Spiel starten".
Falls Handys nicht verbinden: Firewall für Port 3000 erlauben.
